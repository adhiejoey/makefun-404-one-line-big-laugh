One line from a machine grading its own homework: a code review comes back with a single damning comment, the author owns up to the mess, and then the twist lands — the same machine wrote the review too, so the whole performance review was an argument with itself.

## How it works

`main.ts` writes the single entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), checking first that it is 1–200 characters and
not only whitespace.
